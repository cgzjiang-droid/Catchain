# Slice 8：审核队列与反馈指标

目标：把 Slice 6–7 已保存的候选、验证问题、证据和历史决策组织成可执行的人工审核闭环。

- [x] Task 1：审核队列投影
  - 按项目、字段、validation_status、问题code和证据完整度筛选。
  - 明确优先级：证据缺失、冲突、日期/格式错误、低置信度和待裁决。
  - 输出候选ID、原值、错误位置、原文证据、当前正式值和版本身份。
- [x] Task 2：审核纠错工作流
  - 保留草稿和错误位置，修正后复用同一证据校验入口。
  - 保存修改前后值、负责人、原因、权威确认和审核时间。
  - 保持幂等、旧版本不可覆盖、新文档触发重新审核。
- [x] Task 3：审核与抽取指标
  - 统计待审核量、处理时长、通过率、unresolved率、重复返工原因和字段覆盖率。
  - Gold未冻结时不把处理结果称为准确率。
  - 输出可用于5%→10%→30%灰度准入的指标快照。
- [x] Task 4：审核台交付验收
  - CLI/最小接口先闭环，再决定是否需要独立前端。
  - 测试错误定位、修改前后值、冲突裁决、版本重审和指标快照。

Slice 8 工程闭环已完成，不引入Agent；普通Workflow足够。Review Agent仍是后置可选项。
